# 가족 메신저

가족끼리만 쓰는 메신저입니다. 가족 중 한 명이 **서버**를 실행하고, 모두 **안드로이드 앱**을 설치해서 접속합니다.

- 가족 단체방 + 가족 구성원끼리 1:1 대화
- 사진 보내기 (자동으로 줄여서 전송, 눌러서 크게 보기)
- 실시간 메시지 수신과 새 메시지 알림 (앱을 닫아도 동작)
- 읽음 표시(카톡의 "1"처럼 안 읽은 사람 수)와 채팅방·탭의 안 읽은 메시지 개수
- 메시지 길게 누르기: 이모지 반응(❤️👍😂😮😢🙏), 답장, 복사, 삭제
- 채팅방 투표 (예: "저녁 뭐 먹을까?", 여러 개 선택 가능 옵션)
- 프로필 사진·이름·**말풍선 색** 변경 (채팅 탭 오른쪽 위 내 사진). 가족마다 고유 색이 있어 누가 보낸 메시지인지 한눈에 보여요
- **가족 일정**: 함께 보는 달력, 매년 반복(생일·기념일), 전날·당일 아침 알림
- **함께 쓰는 목록**: 장보기·할 일 목록, 체크하면 모두에게 바로 반영
- **1년 전 오늘**: 예전 이날 올린 스토리를 다시 보여주고 아침에 알림
- **가족 스토리**: 가족 모두가 함께 보는 게시판 하나에 사진·동영상(한 번에 최대 10개)과 글을 올리고, 댓글과 ❤️ 하트 · 👍 좋아요 · 👎 싫어요로 반응
  (올릴 때 자동으로 크기를 줄임: 사진은 긴 쪽 1600px, 동영상은 720p로 변환)
  인스타그램처럼 3열 바둑판으로 보이고, 누르면 게시물이 열림. 내가 올린 게시물은 글과 사진·동영상을 수정 가능
  (좋아요와 싫어요는 둘 중 하나만 선택, 내가 올린 글과 댓글만 삭제 가능, 새 스토리와 내 글에 달린 댓글은 알림)
- **음성통화·영상통화** (1:1 대화방 오른쪽 위 📞 버튼). 안드로이드 ↔ 아이폰 웹앱끼리도 통화 가능, 통화 기록이 대화방에 남음
- 가족 코드를 아는 사람만 가입 가능

```
server/   Node.js 서버 (Express + WebSocket + SQLite)
android/  안드로이드 앱 (Kotlin + Jetpack Compose)
```

## 1. 서버 실행 (집 PC)

집에서 항상 켜두는 PC에서 실행하세요.

1. [Node.js](https://nodejs.org) **LTS 버전**(22 이상)을 설치합니다.
2. `server` 폴더에서 실행 파일을 **더블클릭**합니다.
   - Windows: `start-windows.bat`
   - Mac: `start-mac.command` (처음엔 우클릭 → 열기)
3. 처음 실행하면 **가족 코드**를 물어봅니다. 가족에게 알려줄 코드를 정해서 입력하세요 (다음부터는 묻지 않습니다).
4. 창에 표시되는 주소(예: `192.168.0.10:3000`)를 휴대폰 앱의 "서버 주소"에 입력합니다.

- Windows에서 "방화벽에서 액세스를 허용하시겠습니까?"가 뜨면 **개인 네트워크**에 체크하고 허용하세요.
- PC를 켤 때 서버가 자동으로 켜지게 하려면 Windows에서 `install-autostart-windows.bat`를 한 번 실행하세요.
  Mac은 시스템 설정 → 일반 → 로그인 항목에 `start-mac.command`를 추가하면 됩니다.
- PC가 절전 모드로 들어가면 서버도 멈춥니다. 전원 설정에서 절전 모드를 꺼두세요.
- 공유기가 PC에 주는 IP 주소가 바뀌면 앱에 다시 입력해야 합니다. 공유기 설정에서 이 PC에 고정 IP를 지정해두면 편합니다.

명령어로 실행하려면:

```bash
cd server
npm install
npm start                          # 처음 실행 시 가족 코드를 물어봄
FAMILY_CODE=우리집코드 npm start     # 또는 환경 변수로 지정
```

| 환경 변수     | 설명                                   | 기본값  |
|---------------|----------------------------------------|---------|
| `FAMILY_CODE` | 가입할 때 입력하는 가족 코드           | 처음 실행 시 입력 |
| `PORT`        | 서버 포트                              | `3000`  |
| `DATA_DIR`    | 대화 내용과 사진을 저장할 폴더         | `data`  |
| `REMINDER_HOUR` | 일정·추억 알림을 보내는 시각 (서버 PC 시간 기준) | `9` |

일정 알림은 서버 PC의 시간대를 기준으로 보냅니다. 그 시각에 휴대폰이 꺼져 있었다면 다음에 연결될 때 받습니다.

`data/` 폴더에 모든 대화와 사진이 저장되니 주기적으로 백업하세요. 가족 코드를 바꾸려면 `data/config.json`을 지우고 다시 실행하세요.

### 밖에서도 접속하려면

**우리 집 주소: `https://family.uhoui.com`** (Cloudflare 고정 주소. 앱 서버 주소 칸에는 `family.uhoui.com`만 입력해도 됩니다)

- **같은 와이파이에서만 사용**: 앱에 서버 PC의 내부 IP(예: `192.168.0.10:3000`)를 입력하면 됩니다.
- **밖(LTE/5G)에서도 사용**: 다음 중 하나를 권장합니다.
  - [Tailscale](https://tailscale.com) 같은 VPN으로 가족 휴대폰과 서버를 연결 (가장 간단하고 안전)
  - 클라우드 서버에 올리고 Caddy/Nginx 등으로 **https** 적용 후 `https://주소` 입력
  - 공유기 포트포워딩은 가능하지만, 암호화되지 않은 `http`로 인터넷에 노출되므로 권장하지 않습니다.

## 2. 앱 설치

- **GitHub에서 받기**: 저장소의 Actions 탭 → 최신 `Build` 실행 → `family-messenger-apk` 다운로드 후 휴대폰에서 설치 ("출처를 알 수 없는 앱" 설치 허용 필요)
- **직접 빌드**: Android Studio로 `android/` 폴더를 열고 실행하거나, `cd android && ./gradlew assembleDebug`

앱을 열고 **가입하기** → 서버 주소, 가족 코드, 이름, 아이디, 비밀번호를 입력합니다.

## 3. 아이폰 (웹앱)

서버가 아이폰·PC용 웹앱도 함께 보여줍니다. 안드로이드 앱과 같은 대화·스토리·일정·목록을 씁니다.

1. 아이폰 **사파리**로 서버 주소(https)를 엽니다.
2. 아래쪽 **공유 버튼 → 홈 화면에 추가**를 누릅니다.
3. 홈 화면에 생긴 **가족 메신저** 아이콘으로 열고 로그인(또는 가입)합니다.
4. 채팅 탭 위의 **새 메시지 알림 받기 → 켜기**를 누르고 알림을 허용합니다.

- 알림은 **iOS 16.4 이상**, **홈 화면에 추가한 앱**, **https 주소**에서만 동작합니다.
- 사진은 올릴 때 자동으로 줄입니다. 동영상은 원본(mp4·mov) 그대로 올라가니 100MB 이하로 짧게 올려주세요.
- PC 브라우저(크롬·엣지·사파리)에서도 같은 주소로 쓸 수 있습니다.

### https 주소에 대해 (Cloudflare Tunnel)

`cloudflared tunnel --url http://localhost:3000`처럼 계정 없이 만든 **임시 주소(…trycloudflare.com)는 cloudflared를 다시 켤 때마다 바뀝니다.**
주소가 바뀌면 홈 화면에 추가한 앱과 알림이 예전 주소를 가리키게 되어, 가족 모두 새 주소로 다시 추가하고 알림을 다시 켜야 합니다.
그래서 지금은 도메인을 연결한 **이름 있는 터널(named tunnel)** 로 고정 주소 `https://family.uhoui.com` 을 씁니다.
(안드로이드 앱은 예전 trycloudflare 주소로 로그인되어 있으면 알아서 새 주소로 바꿉니다.)

알림용 키는 `data/vapid.json`에 저장됩니다. 이 파일을 지우면 모든 기기에서 알림을 다시 켜야 하니 `data/` 폴더째 백업하세요.

## 4. 게임 추가·수정하기 (앱 업데이트 필요 없음)

맨 오른쪽 **게임** 탭은 서버에 있는 HTML 게임을 보여줍니다. 안드로이드 앱과 아이폰 웹앱 모두 서버에서 바로 불러오기 때문에,
**서버 PC에서 파일만 고치면 가족 모두에게 바로 반영**됩니다. 앱을 다시 빌드하거나 서버를 재시작할 필요가 없습니다.

```
server/web/games/
  games.json            ← 게임 목록
  family-games.js       ← 점수 저장·가족 순위 도우미
  memory/index.html     ← 예시: 짝 맞추기
  mole/index.html       ← 예시: 두더지 잡기
```

새 게임 넣는 법:

1. `server/web/games/` 안에 영문 폴더를 만들고(예: `quiz`) 그 안에 `index.html`을 넣습니다. 그림·소리 파일도 같은 폴더에 두면 됩니다.
2. `games.json`에 한 줄을 추가합니다.
   ```json
   { "id": "quiz", "title": "가족 퀴즈", "emoji": "❓", "description": "우리 가족 얼마나 알까?", "scoreOrder": "high", "scoreUnit": "점" }
   ```
   - `id`는 폴더 이름과 같아야 합니다 (영문 소문자·숫자·`-`·`_`).
   - `scoreOrder`: 점수가 높을수록 1등이면 `"high"`, 낮을수록(횟수·시간) 1등이면 `"low"`.
3. 앱에서 게임 탭을 새로고침하면 바로 나타납니다.

게임에서 가족 순위를 쓰려면 `index.html`에 도우미를 불러오세요:

```html
<script src="/games/family-games.js"></script>
<script>
  // 게임이 끝났을 때
  const result = await FamilyGames.submitScore(점수);          // 저장하고 순위 받기 (result.record: 내 최고 기록인지)
  FamilyGames.renderLeaderboard(document.getElementById('rank'), result);  // 순위표 그리기
</script>
```

`FamilyGames.me()`로 지금 하는 가족의 이름도 알 수 있습니다. `games.json` 문법이 틀리면 게임 목록이 비어 보이니, 고친 뒤 게임 탭이 비면 쉼표·따옴표를 확인하세요.

## 5. 전화(음성·영상통화) 설정

통화 소리와 영상은 서버를 거치지 않고 **휴대폰끼리 직접** 주고받습니다. 서버는 "전화 왔어요 / 받았어요" 신호만 전달해서 집 PC 사양과는 상관없습니다.
같은 와이파이에서는 설정 없이 바로 되지만, **밖에서(LTE/5G) 걸 때는 통신사 사정으로 직접 연결이 막히는 경우가 많아서** 중계 서버(Cloudflare TURN)를 켜두는 것을 권장합니다.

### Cloudflare TURN 켜기

1. [Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/calls) 로그인 → 왼쪽 메뉴 **Realtime(실시간) → TURN Server** → **Create(만들기)**
2. 이름을 정하면(예: `family`) **Turn Token ID** 와 **API Token** 이 나옵니다. API Token은 한 번만 보이니 바로 복사하세요.
3. 서버 PC의 `server/data/config.json` 을 메모장으로 열어 두 줄을 추가합니다 (쉼표 주의):
   ```json
   {
     "familyCode": "기존 가족 코드 그대로",
     "turnKeyId": "Turn Token ID 붙여넣기",
     "turnKeyToken": "API Token 붙여넣기"
   }
   ```
   (또는 환경 변수 `TURN_KEY_ID`, `TURN_KEY_API_TOKEN` 으로 넣어도 됩니다.)
4. 서버를 다시 실행하고 창에 **`통화 중계(Cloudflare TURN): 켜짐`** 이 보이면 완료.

이 키는 서버에만 두고 채팅 등에 붙여넣지 마세요. 휴대폰은 통화할 때마다 서버에서 하루짜리 임시 비밀번호만 받아 갑니다.

**요금**: Cloudflare TURN은 **매달 1,000GB까지 무료**이고 넘는 부분만 1GB당 $0.05입니다 (직접 연결된 통화는 중계를 안 거쳐 아예 세지 않음).
영상통화 1시간이 대략 1GB 안팎이라 가족끼리 쓰기에는 사실상 무료입니다.

### 전화 받기

- **안드로이드**: 앱이 꺼져 있어도 벨이 울리고 잠금화면에 전화 화면이 뜹니다 (무음/진동 모드를 따름). 처음 걸거나 받을 때 마이크·카메라 권한을 허용하세요.
  안드로이드 14 이상에서 잠금화면에 전화 화면이 안 뜨면 설정에서 **"전체 화면 알림"**(삼성: 설정 → 애플리케이션 → 특별한 접근 → 전체 화면 알림)에 가족 메신저를 허용해주세요.
- **아이폰 웹앱**: 웹앱은 백그라운드에서 벨을 울릴 수 없어서 **"○○님의 영상통화 · 눌러서 받기" 알림**으로 옵니다. 45초 안에 알림을 누르면 받을 수 있어요.
  (웹앱이 열려 있을 때는 바로 전화 화면이 뜹니다.)

## 알림에 대해

이 앱은 구글 Firebase 없이 직접 만든 서버를 쓰기 때문에, 앱이 서버와 연결을 유지하는 방식으로 알림을 받습니다.
그래서 알림창에 **"새 메시지를 기다리는 중"** 이라는 작은 상시 알림이 표시됩니다 (알림 설정에서 "실시간 연결" 채널을 숨길 수 있습니다).

삼성 등 일부 휴대폰은 배터리 절약을 위해 백그라운드 앱을 종료하므로, 알림이 늦게 오면
**설정 → 애플리케이션 → 가족 메신저 → 배터리 → 제한 없음**으로 바꿔주세요.

